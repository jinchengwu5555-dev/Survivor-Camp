# 游戏与剧集参考

> 这几部作品没有原文，根据对作品的公开了解整理机制。**只借鉴机制，不使用任何名字、角色、地图、剧情和美术造型。**

## 三角洲行动（搜打撤）

- **搜、打、撤**：进图搜东西，打人或怪，赶在时间内到撤离点撤出去。撤不出去，带进去的和搜到的都丢了。
- **安全箱**：一个小格子，里面的东西死了也不会丢。
- **背包格子**（已采用）：不同物品占不同格子，好东西往往很大。
- **价值感**：“大红”（极稀有的高价值物品）一出，全场心跳加速。
- **干员分工**：突击、支援、工程、侦察，各有道具。

## 骑马与砍杀 2

- **从小队到领主**：一开始只有几个人，招人、带兵、打仗、拿到封地，最后建国。
- **兵种树**：新兵打仗攒经验，升级成不同兵种（步兵 / 弓手 / 骑兵）。
- **俘虏**：打赢后俘虏敌人，可以招降、关押或换赎金。
- **商队和贸易**：不同城镇物价不同，开商队跑贸易路线。
- **同伴与家族**（部分已采用：羁绊、站位）：同伴有技能，可以派去当队长、管理封地；会结婚生子，下一代接班。
- **战场指令**：冲锋、守住、跟我来，士气低了会溃逃。

## 燕云十六声（开放世界武侠）

- **奇遇**：在世界里随手可以触发的小故事，有的有后续。
- **万物可交互**：NPC 有自己的作息，能对话、帮忙、捣乱。
- **生活玩法**：钓鱼、弹琴、下棋、喝酒、做饭等小游戏，和主线无关但很解压。
- **风物志**：收集各地的风土人情、物件，做成图鉴。
- **天气与昼夜**：雨天、夜晚影响玩法和氛围。

## 杀戮尖塔（Roguelike 卡牌）

- **分叉路线图**：每一层有几条路可选，路上有普通战斗、精英、营火、商店、问号事件、宝箱，看得见但要取舍。
- **营火：休息还是升级**：回血或强化一张牌，二选一。
- **遗物**：每一局拿到的被动道具，组合出不同玩法。
- **进阶难度**：通关后解锁更高难度，每一级加一条限制。
- **每日挑战**：所有人同一个种子、同样的修正条件，比分数。

## 植物大战僵尸

- **塔防 + 阳光经济**：阳光（资源）种植物（防御），植物打僵尸。
- **一大波僵尸正在接近**：明确的波次提示，最后一波最猛。
- **最后防线**：每一行有一台割草机，僵尸到底时救你一次，用掉就没了。
- **僵尸花样多**：戴铁桶的、撑杆跳的、拿报纸的（报纸打掉会暴怒）、挖地道的……每一种逼你换一种打法。
- **出发前选卡**：每关开始前从全部植物里选几张带上。
- **禅境花园**：给植物浇水、施肥，攒钱。纯放松。
- **夜晚、浓雾、屋顶关卡**：同样的玩法，换环境就换策略。

## 潜水员戴夫

- **白天潜水、晚上开店**：白天下海抓鱼（有氧气和负重限制），晚上用抓到的鱼开寿司店，赚的钱升级装备。两个循环互相喂养。
- **员工**：雇人、培训、分配岗位，员工有自己的特长。
- **副业**：种菜、养鱼，供给店里的食材。
- **每天的海不一样**：浅海、深海、夜潜，不同区域、不同鱼。
- **图鉴和委托**：收集所有鱼类，完成客人和 NPC 的委托。
- **小游戏**：大量一次性的小玩法让节奏不单调。

## 行尸走肉（剧集，只借机制和情绪）

> **版权红线**：不使用任何角色名、地名、组织名、标志性造型和原剧情。

- **声音吸引尸群**：开枪、敲打、汽笛都会把附近的丧尸引过来。
- **尸群迁徙**：巨大的尸群像潮水一样缓慢移动，挡在路上的一切都会被淹没；可以提前改道、引开。
- **伪装**：把丧尸身上的东西抹在身上，混在尸群里穿过去。
- **人死后会变**：营地里有人病死、老死，如果不及时处理，会在夜里变成丧尸。
- **农场和高墙是避难所**：一片农场、一座有围墙的设施，就是理想的家。
- **收保护费的强大势力**：一伙人定期来收一半物资，不给就杀人立威。
- **太好了的“避难所”**：广播里说“这里安全，欢迎所有人”，到了才发现是陷阱。
- **社区之间的贸易与联盟**：几个营地互相交换物资、技术，共同对抗威胁。
- **领导者的道德滑坡**：为了保护营地，越来越能下得去手，大家开始害怕他。
