# 《黑暗血时代》（天下飘火，网络小说，约 1960 章，连载）

> 分析方式：通读目录，精读前 10%（末日初期的生存部分）。后期是星际修炼，和我们的题材无关。

## 一句话

太阳突然消失，地球陷入永夜和严寒，巨型虫群从地下涌出。主角在被军方管控的小区里领口粮，后来随着难民大潮逃出城市。

## 世界观要点

- **永夜与严寒**：没有阳光，气温一路下降，植物死去。光和热成了最稀缺的东西：火把、手电、车灯，城市只剩下“微光”。
- **军方配给**：居民被禁足在家，每天下楼领军方分配的口粮。口粮越来越少，有人和士兵起了冲突，几个城区发生暴动，军队逐步放弃边缘区域，收缩到核心城区。
- **举着火把的搜寻队**：幸存者自发结成松散的团体，举着火把成群出去找吃的——超市、菜场搜完了，连下水道里的老鼠都被翻出来。
- **虫群**：赤甲虫、青甲虫等巨型昆虫，单只很弱、群居，成群出现时非常可怕。“以战养战”：用虫子身上的东西打造战甲、武器。
- **难民大迁徙**：整座城市的人坐卡车、步行逃难，零星的火把和车灯连成人潮。路上用值钱的东西换快要变质的食物，消息比金子还值钱。
- **限电的地下城**：后方城市靠一座不稳定的小电站维持，全城强制限电，只有必要的道路有灯。
- **极端天气**：很多人没死在怪物口下，却死在暴风、严寒里。

## 可借鉴

- 光照 / 照明作为资源：夜晚、阴天需要照明，没有灯就更危险。
- 配给制与暴动：食物不够时按人头配给，配给太少会有人闹事。
- 虫群：数量多、单体弱的新敌人类型；击杀后掉“甲壳”做护甲。
- 消息的价值：情报（地图、路线）可以拿来交易。
- 难民潮：一次性涌来很多人，收不收、收多少。

## 不建议采用

- 角色名（楚云升等）、城市名、各种专有名词（元符、命源、枢机等）。
- 后期的星际修炼体系。
