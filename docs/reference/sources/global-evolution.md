# 《全球进化》（咬狗，网络小说，约 330 万字）

> 分析方式：通读目录（约 500 章），按关键词在全书均匀抽样精读。

## 一句话

一场持续两年的粉红色雾气之后，地球上**所有生物同时开始进化**：植物会捕猎、老鼠能吃猫、微生物让食物几小时就腐烂。一群复读生和军人在“食物链重新洗牌”的世界里求生。

## 世界观要点

- **末日不是丧尸，而是整个生态失控**。原来的食物链被打乱：
  - 植物同时成了捕食者，比如会吸血的藤条、会攻击的柳树
  - 素食动物和肉食动物的界限消失，谁的个体强大谁就吃谁
- **黑红色浓雾**：遮挡视线、**吸收声音**，人类在雾里又聋又瞎，而变异动物靠嗅觉捕猎。
- **微生物暴走**：尸体两三个小时就腐烂，面包当天发霉，只有真空包装和加了防腐剂的食物能放。
- **人类也在变异**，而且方向各不相同：
  - 有人“脑域”进化，记忆力和计算力暴涨，甚至能预判未来
  - 有人嗅觉、“思觉”变得极其敏锐
  - 变异是天赋，也可能是诅咒
- **人类社会**：军队发放种子（一种叫“梁豆”的末日作物），混乱的城区里有黑帮、雇佣兵、酒馆。后期出现两栖人、海底人等新人种。

## 叙事手法

- **“第二天一早”循环**：大量章节以“第二天一早，所有人同时睁开眼睛”开头，形成日复一日求生的节奏感。这和我们“存活第 X 天”的核心数据天然契合。
- **时间跳跃**：中期直接跳到“四年后”，重新介绍老角色（“四年后的小静”“四年后的李轻水”），让读者感受到世界和人物的变化。
- **科普式求生**：角色用生物学知识分析危险，比如食物链的三种类型、怪树靠什么判定猎物。“平凡人的智慧”是全书的一大卖点。
- **道德拷问**：有“道德与生命”“杀人”“没有对错”“杀伐不果断”等章节，主角一再面对为了活命要不要杀人的选择。
