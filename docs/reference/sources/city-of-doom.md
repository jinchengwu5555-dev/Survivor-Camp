# 《末日之城》（十阶浮屠，网络小说，约 700 章，已完结）

> 分析方式：通读目录，按关键词抽样精读前中后段。书里有大量成人内容和食人情节，这些**一律不采用**，只记录机制和情绪。

## 一句话

活尸爆发后，一个普通上班族从被困的写字楼开始，一路向外求生：楼顶等救援、下水道转移、县城搜刮、进入聚集地、离开去西北，最后建立自己的势力。

## 世界观要点

- **被困在一栋楼里**：开篇是写字楼里的十几个人，办公室、天台、楼梯间就是全部世界。谁拿着钥匙、谁掌管食物，就有了话语权。
- **救援的倒计时**：直升机接走了少数人，剩下的人在等“第二批”。主角给自己定了期限：再等半个月救援不来，就自己找出路，而能带走的人有限。
- **路线即剧情**：天台 → 下水道 → 防空洞 → 县城 → 聚集地 → 公路 → 列车 → 海上的船 → 沙漠里的城。每一段都是一种新的生存环境。
- **聚集地的秩序**：有城主、有派系、有内奸。研究所的配方被偷，主角先暗中观察，不急着抓人，免得人心惶惶。
- **“太好了”的避难所**：路上遇到一个热情好客、物资充足的村子，背后藏着可怕的秘密。主角吃饭时就起了疑心，半夜摸黑离开。
- **列车和船当营地**：一整列火车或一艘船就是一个移动的聚集地，车厢之间的防守、断开车厢甩掉尸群，都是很有画面感的桥段。
- **病毒研究**：活尸试验场、同化剂、克隆，层层揭开病毒的秘密。

## 可借鉴

- 等救援还是自己走：给“希望”设一个期限，期限到了要做抉择。
- 内奸要“观察”而不是立刻抓：营地里的可疑行为要攒证据。
- 路线式的大地图：营地迁徙时每一站环境不同。
- 移动营地（车队、列车、船）。

## 不建议采用

- 角色名（刘天良、萧澜、严如玉等）、地名和势力名（良王府、浮华城等）。
- 成人内容、食人情节、对女性的物化描写。
