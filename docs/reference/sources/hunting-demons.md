# 《狩魔手记》（烟雨江南，网络小说，约 670 万字）

> 分析方式：通读卷章目录（六卷约 70 个大章），按关键词在全书均匀抽样精读。

## 一句话

核战之后，辐射和变异席卷世界，秩序彻底瓦解。一个从废土最底层成长起来的少年“苏”，靠进化能力在猎人、公司、议会、帝国和“使徒”之间杀出一条路。

> 简介原话的精神：“当欲望失去了枷锁……左边是地狱，右边也是地狱。”

## 世界观要点

- **辐射废土**：地表水体全部带辐射，湖里的鱼普通人不能吃。人类在几代之后开始出现稳定遗传的“变异组织”，对辐射的耐受力提高。
- **进化点与能力域**（全书最核心的成长系统）：
  - **进化点来源**：基因改造药剂、战斗，也有原因不明的自然生成
  - **能力域**：进化点投入格斗域、类法术域、感知域、神秘学等“能力域”，自动生成一阶到十阶的能力，比如强化防御、寒冰、雷电、嗅觉强化
  - **配方能力**：用“配方”可以定向获得特定能力，比自然生成的更稳定、更贵
  - **加点取舍**：同样的进化点，可以“开一个新的高阶能力”，也可以“升级多项低阶能力”，这是取舍
  - **禁忌捷径**：直接吸取、掠夺别人的基因可以飞速变强，但被视为“不归路”，风险极大
- **猎人职业**：捕杀变异生物卖给基地，它们的基因是新药剂的来源。猎人和佣兵按战绩分级，由公司或基地发执照（“一级猎人和初级雇佣军”）。
- **基地发布任务**：比如探查地铁通道，分两档报酬，探到洞穴给 500 元，打通安全通道给一支基因药剂。风险和报酬明码标价。
- **硬币经济**：没有银行，只流通硬币，钱多了背不动，所以要尽快花掉。
- **聚居地的狮群秩序**：
  - 一把还能开火的左轮就是强者，有半自动步枪就能成为统治者
  - 几百人的聚居地里有首领、武装、酒吧、诊所，诊所的规模代表聚居地的等级
- **聚居地的发展瓶颈**：熬过第一个冬天只是开始，想进一步发展，必须解决工业母机和能源。
- **势力**：
  - 大公司：卖药剂、武器、执照
  - 暗黑龙骑：军事集团，军阶和扈从制度
  - 血腥议会
  - 太阳帝国：以能力划分地位的分封领主制
  - “选民”：流水线制造的改造战士
  - “使徒”：半人半神的高阶存在，与外星遗留物有关
- **开篇的情感锚点**：少年和女孩相依为命，靠一只水蛭三天一个轮回地活下来。三年后水蛭死了，少年说“我们得去聚居地了”，女孩说“我怕”，少年说“不要怕，我会保护你的”。

## 叙事手法

- **冷峻克制的文风**：大量废土环境描写，杀伐果断，但主角内心始终保留一块柔软的地方。
- **卷名就是主题**：动荡年代、我的心深如大海、在光与暗之间、风雨如晴、使徒传说。每卷一个情绪主题，适合我们“季”的命名方式。
- **“上 / 中 / 下”章节结构**：一个事件分几段写完，节奏感强。

## 不建议采用

- 狮群式的性暴力秩序、奴隶制：不适合休闲玩家，审核也过不了。
- 外星文明、使徒、选民这类“宇宙级”设定：和我们小镇求生的尺度不符，最多在后几季作为远景。
- 作者的专有名词（苏、暗黑龙骑、血腥议会、选民、使徒等）。
