# 《蹉跎》（随风飘摇，网络小说，约 430 万字，已完结）

> 分析方式：通读目录（约 340 章，两卷），按关键词在全书均匀抽样精读。

## 一句话

主角从休眠舱中醒来，发现世界已经毁灭，自己被改造成了半机械的“仿生躯体”。他带着一群古怪的伙伴，在变异生物、邪教、帮派和卫星武器之间挣扎求生。

## 世界观要点

- **醒来已是末日**：主角是战前“仿生躯体计划”里唯一的平民实验品，大脑被移植进人造身体。醒来后要自己搞清楚世界发生了什么，还要搜寻父亲留下的线索。
- **破铁乡式的边境小镇**：
  - 没有管理者，谁的武器厉害、势力大，谁就管着小镇，入口的守卫隔半年就换一拨人
  - 流浪者按规矩交纳粮食或清水，就能在镇里过冬
- **粮食就是命脉**：方圆几百里唯一能稳定产粮的村子被邪教攻破，整个地区的人都会挨饿。一个据点被毁，会连锁影响一片区域。
- **势力林立**：
  - 永生教：邪教，攻打村庄，把村民卖做奴隶
  - 教会、三合会、商业协会：幕后势力庞大
  - 各路帮派
  - 各势力之间“互相合作又互相竞争”，关系复杂
- **死人开关**：每个帮派老大都掌握着物资库的密码锁。老大死了，谁都拿不到物资，手下只能沦为奴隶或流浪汉，所以没人敢轻易杀老大。
- **病毒感染者**：狂犬病毒变异，感染者眼睛通红、动态视力是常人两倍，爆发力惊人，成群冲锋。
- **变异生物当食物**：油老鼠被烤着吃，还有荒原巨蝎、半米长的“狼蚂蚁”；也有卫星武器、生化武器、地下基地等战前遗留的高科技。
- **末日民俗**：老人和孙子打招呼说“祝蘑菇丰收”，回答“老鼠满仓”。**蘑菇和老鼠成了末日里最实在的富足象征**。
- **基地建设**：主角的盟友给基地里所有人每天安排两小时文化课，还制订了“繁衍二百年”的长期计划。

## 伙伴与小队配合（很有参考价值）

主角的小队由非人类伙伴组成，各有明确分工：
- **主角**：改造人，火力支援，扫描侦察。
- **猫女**：半猫半人，擅长潜伏和暗杀。刚认识时呆萌、问“枪子是什么？好吃吗？”，后来成为最可靠的同伴。
- **太岁**：能分裂出多个分身吸引火力，还能伪装成岩石。
- **天狼星、暗割、人狼**：每个都有独特能力和性格，彼此斗嘴（“自从你苏醒到现在，有没有连着遇到三件好事的时候？”）。

小队战术是：遇到伏击时，主角用火力掩护猫女潜行暗杀，太岁的分身冲击敌方阵线分散注意力。**这正是我们自动战斗里“职业分工 + 技能配合”可以追求的效果。**

## 叙事手法

- 小人物的悲欢离合：主角并不强大，也不伟大，一路都在为生存计较得失。
- 危机后发现真相：日记、程序、卫星资料层层揭开“主控者”的阴谋。
- 章节常分上下篇，节奏紧凑，适合改成“一集一个悬念”。

## 不建议采用

- 奴隶买卖、女性被药物改造出售、性交易等内容：不适合休闲玩家，也过不了微信审核。
- 主角对人命的冷漠（改造后“漠视人类生命”）：和我们“守住人性”的主题相反，只能作为反派的特征。
- 作者的人名和势力名（王平、猫女、太岁、永生教、三合会、破铁乡等）。
