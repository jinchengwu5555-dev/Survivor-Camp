# 《剑风传奇》（三浦建太郎，漫画）

> 没有提供原文，以下根据对作品的公开了解整理。它是黑暗奇幻，不是末日题材，但在“绝境中挣扎”“团队与背叛”“夜晚恐惧”三方面对我们很有启发。

## 一句话

孤儿出身的佣兵格斯加入了“鹰之团”，找到了归属，却被团长格里菲斯为了野心献祭。他背负着会在夜晚招来恶灵的“烙印”，拿着一把巨剑，在无尽的战斗中挣扎前行。

## 值得借鉴的内容

### 1. “挣扎者”精神

主角面对远强于自己的命运，唯一的武器就是**不放弃**。这正好对应我们“活下去”的核心体验：营地一次次被尸潮冲击，但只要还有人在，就继续守。

可以作为游戏整体的精神基调，用在宣传语和季终旁白上。

### 2. 夜晚 = 恐惧

烙印让恶灵每到夜晚就来袭，主角几乎无法安眠。“白天准备，夜晚死守”的节奏感非常强。

我们已经有尸潮夜袭，可以进一步：
- 特殊的夜晚（血月夜）尸潮更凶（点子 R26）
- 让“守夜前的准备”成为每天的固定节奏

### 3. 佣兵团：归属感与群像

鹰之团是一群出身卑微的人组成的“家”。篝火旁的闲聊、共同的战绩和荣誉，让读者和他们产生感情，所以之后的悲剧才那么有冲击力。

对我们的借鉴：营地群像、小队番号和荣誉（点子 R13）。**先让玩家爱上角色，失去才会痛。**

### 4. 背叛与野心

最信任的领袖为了梦想出卖了所有同伴。背叛者不是单纯的坏人，他的野心在前面铺垫了很久。

对我们的借鉴：长线背叛剧情（点子 R14）；“为了活命献祭所爱之人”的首领（点子 R30）。

### 5. 狂战士状态

穿上一副甲胄后能无视疼痛和极限战斗，但会伤害自己的身体，还会逐渐失去理智。

对我们的借鉴：英雄的“极限爆发”技能（点子 R29），战后必定重伤。

### 6. 创伤与陪伴

同伴卡思嘉在惨剧后失去心智，主角后续的旅程很大一部分是守护她、带她寻找治愈的方法。创伤不是一次事件，而是长期的状态。

对我们的借鉴：幸存者的心理创伤（点子 R12）；守护一个需要照顾的角色（点子 R09）。

### 7. 旅途中的新伙伴

后期主角身边聚起一群性格各异的同伴：话痨的小精灵、少年小偷、贵族少女、小魔女。沉重的故事中，他们带来了温度和幽默。

对我们的借鉴：点子 R10、R38。

## 不建议采用

- “蚀”那一段的极端暴力和性暴力：完全不能用。
- 恶魔、魔法、宗教神话：不符合我们的末日题材。
- 作品专有名词和形象：格斯、格里菲斯、鹰之团、贝黑莉特、斩龙剑，以及格斯标志性的巨剑和独臂炮等造型。
