# 《末日孢子》（江小黑，网络小说，约 130 节，连载）

> 分析方式：通读目录，按关键词抽样精读。篇幅较短，以日记体和多视角群像为主。

## 一句话

一场由真菌孢子引起的瘟疫在南方海滨城市爆发。几个普通人（咖啡店员、实习牙医、护士……）用日记的方式记录了从封城、逃亡到登岛求生的过程。

## 世界观要点

- **日记体**：每一章以日期开头（“12 月 10 日，大雨刚过，开始倒数……”），像幸存者亲笔写下的记录。
- **感染的过程很具体**：孢子随空气、雨水传播；感染后出现红斑、溃疡、结痂，几十个小时后彻底变异。被感染的人还有一段“清醒”的时间。
- **疫苗冷冻盒**：一小盒疫苗，电池只剩两格，还能撑一个星期。时间到了疫苗就失效——必须在电池耗尽前送到。
- **古寺石板**：一块古代石板上画着和这场灾难很像的情景，暗示孢子很久以前就出现过。
- **小区之夜、骑楼穿行**：南方城市特有的街景：骑楼、阳台、铁门、小区。在骑楼上方穿行躲避尸群。
- **海上逃亡与汽笛 SOS**：坐船离开港口，用船上的汽笛鸣出 SOS 求救，声音传出两千米——但也可能引来别的东西。
- **两道大门的基地**：岛上的基地有两层大门、一座桥，出去以后没有授权就回不来。
- **融合者**：被孢子改造的怪物，其实是主角找了很久的朋友。按下焚烧键，还是放过它？

## 可借鉴

- 日记体日志：营地日志用“第 N 天”的日记口吻写，增强代入感。
- 感染倒计时：被咬的人不是立刻变异，有一段清醒时间可以做选择。
- 限时物品：疫苗、冷藏的药，过期就没用了。
- 汽笛 / 信号：发出求救信号能招来幸存者，也会招来尸群。
- 曾经的朋友变成怪物：守夜时遇到一只“穿着熟悉衣服”的丧尸。

## 不建议采用

- 角色名（王宁惠、青红、宏刚等）、地名（大屿、河门等）、“三叶草疾病中心”“千叶寺”等专有名词。
