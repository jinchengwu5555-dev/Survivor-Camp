# 《神魔养殖场》（黑瞳王，网络小说，约 1180 章，已完结）

> 分析方式：通读目录，精读前 20%（学校被困、组队求生、建村子的部分）。后期是神魔修炼，和我们的题材无关。

## 一句话

一所大学整体塌陷进“天坑”，掉进一个满是怪物的未知森林。两千个学生被困在校园里，粮食只够两天，主角带着一支三十多人的小队走出去求生，后来建立村子、驯化怪物。

## 世界观要点

- **整座学校就是营地**：教学楼、食堂、宿舍都在，但粮食很快见底。“再不改变，不到两天就没饭吃了”。
- **小队出征**：从两千人里挑出三十一人组成先遣队，走出森林找食物和出路。谁走在队伍最后面、谁掉队，都是剧情。
- **食物被偷**：夜里少了六大袋食物，等于少了六天的口粮。是谁拿走的？外面还有别的人？
- **轰杀同伴的罪恶感**：被感染、变异的同伴只能亲手解决，事后长期愧疚。
- **建村子、驯化怪物**：村子刚建起来，人手不够。有的怪物性情凶但智商低，抓到后可以驯化来拉车；但驯化需要很多人围捕，还要解决饲料问题。
- **被赶出村子**：主角和村子的掌权者起冲突，被赶出“自由村”。
- **变异进化**：人的身体部位变异（鳞片手掌、蜥蜴臂），获得能力，但也让别人害怕。

## 可借鉴

- 粮食倒计时开局：开局就告诉玩家“粮食还够几天”。
- 夜里食物失窃：一连串调查事件（营地里有内鬼，还是外面有人）。
- 驯化役畜：抓到的野兽驯化后拉车、驮东西，和交通工具、畜栏结合。
- 被流放 / 驱逐：营地里的人因为冲突被赶走，日后可能以敌人或盟友的身份回来。

## 不建议采用

- 角色名（苏羽、雷蕊、孟婷等）、怪物名（角魔马、黄金兽等）、“天坑”“自由村”等专有名词。
- 后期的神魔、修炼、宇宙设定。
