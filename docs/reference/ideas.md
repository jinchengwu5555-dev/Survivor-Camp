# 点子池

从参考作品里提炼出来的点子，没有标“已采用”的**都处于“待定”状态**，等你挑选后再采用。第一批 R01～R40 来自最早的 5 部作品，第二批 R41～R85 来自后来加的小说、游戏和剧集（见第七节）。
-参考作品：蹉跎，狩魔手记，黑暗血时代，末日孢子，末日之城，神魔养殖场，全球进化
-游戏：三角洲行动，骑马与砍杀2，燕云十六声，杀戮尖塔，植物大战僵尸，潜水员戴夫
-电视：行尸走肉
-内容：钓鱼，种菜，养殖（**已采用**：钓鱼在 `core/hunting.ts`，种菜和养殖在 `core/farming.ts`、`farming.json`）
- **来源缩写**：全 =《全球进化》、蹉 =《蹉跎》、狩 =《狩魔手记》、最 =《最后生还者 1》、剑 =《剑风传奇》；第二批：城 =《末日之城》、黑 =《黑暗血时代》、养 =《神魔养殖场》、孢 =《末日孢子》、角 = 三角洲行动、骑 = 骑马与砍杀 2、燕 = 燕云十六声、塔 = 杀戮尖塔、植 = 植物大战僵尸、潜 = 潜水员戴夫、行 = 行尸走肉（剧集，只借机制）
- **工作量**：小 = 只改配置表 / 写事件；中 = 需要加一些代码；大 = 新系统
- **推荐度**：★★★ 强烈推荐，和我们的核心体验高度契合；★★ 值得做；★ 可以放到后期
- **状态**：待定 / 已采用 / 已放弃。采用后改状态，并注明落地到了哪个文件

## 我的推荐：如果只选一批先做

> 第一批（下面 1～5）和成就系统已经全部实现。其余点子你已经决定采用（R33 仍待定），标为“已决定采用（待实现）”。

按“投入小、对核心体验提升大”排序：

1. **R18 日记残页** + **R19 宁静时刻** + **R38 幽默调剂**：只写事件和配置，马上能让游戏更有情感。
2. **R26 血月夜** + **R22 狂暴感染者**：只改配置，让守夜更有节奏。
3. **R10 营地的狗**：可爱，适合做宣传素材，工作量小。
4. **R01 食物腐烂** + **R03 过冬**：让经营有真正的压力，也为第一季后半段提供主线。
5. **R15 悬赏板** + **R25 工坊合成**：给探索更多目标和取舍。

大系统（R24 人类势力、R27 成长树、R20 迁徙）建议等第一季上线、看完玩家数据后再决定。

### 第二批里我最推荐先做的

1. **R73 波次提示 + R74 最后防线 + R75 丧尸花样**：守夜是核心玩法，这三个让每一晚都不一样，工作量不大。
2. **R58 熟悉的丧尸**：和刚做的墓地、羁绊配合，情感冲击最强，也最适合做宣传。
3. **R61 安全箱 + R60 深入搜刮**：让探索背包更有“搜打撤”的心跳。
4. **R52 驯化役畜**：直接接在刚做的畜栏上，打猎 → 养殖 → 交通工具串成一条线。
5. **R78 小委托 + R79 今日情报**：只写配置就能让每天有新目标。
6. **R47 配给制 + R43 太好了的避难所**：一个是经营手段，一个是好写的连锁事件。
