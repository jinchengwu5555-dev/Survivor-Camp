> 状态：草案，等待修改（v0.2：已确定游戏名、死亡机制、战斗方式、主角和背景）
> 标记说明：**【待定】** = 需要你拍板；**【建议】** = 我的推荐，可以推翻

## 1. 一句话概念

**丧尸末日里，你是一个幸存者营地的首领：建设营地、派小队探索废墟、带回同伴，然后在一次次艰难抉择中决定谁能活下去。**

- **游戏名**：**《末日营地》**（上线前需要查商标和同名游戏）
- **背景**：美国乡村小镇“枫谷镇”（虚构）
- **类型**：日漫风丧尸生存 · 营地经营 · 放置探索 · 剧情抉择
- **平台**：微信小游戏，竖屏（之后可同步上架抖音小游戏）
- **目标玩家**：休闲玩家，碎片时间玩，每次 5～15 分钟，一天打开多次
- **参考**：《无尽冬日》的经营和成长节奏 + 《行尸走肉》的剧情张力和人物命运

## 2. 差异化卖点（为什么玩家选我们）

丧尸题材和经营题材的游戏都很多，我们要靠下面三点让玩家记住：

1. **每个幸存者都有自己的故事**：有名字、性格、过去和关系。他们会吵架、会恋爱、会背叛，也会牺牲。玩家在意的是这些“人”，不只是数值。
2. **你的选择真的有后果**：救不救陌生人？食物不够时先饿谁？队友被咬了怎么办？选择会影响士气、人际关系和后续剧情。
3. **像追剧一样玩**：内容按“季 / 集”组织，每集有悬念结尾。主线看完后进入“无尽生存”，营地的故事会一直延续下去。

> 核心体验关键词：**“活下去”的紧张感 + 看着营地一点点壮大的满足感 + 追剧一样的好奇心**

## 3. 核心循环

```
          ┌───────────────────────────────────────┐
          ▼                                       │
  [营地] 建造 / 升级设施 ──► 生产资源 ──► 分配幸存者工作
          │                                       ▲
          ▼                                       │
  [探索] 派小队外出 ──► 遭遇事件 / 自动战斗 ──► 带回物资和新幸存者
          │                                       │
          ▼                                       │
  [危机] 尸潮夜袭 / 剧情抉择 ──► 营地成长或受损 ──┘
```

- **短循环（1～5 分钟）**：收资源 → 升级建筑 → 派探索队 → 处理一个事件
- **中循环（一天）**：推进 1～2 集剧情，打退一次尸潮，解锁一个新区域
- **长循环（几周）**：营地从破超市发展成小镇，完成一季剧情，开启下一季

## 4. 主要系统

### 4.1 营地建设（对应《无尽冬日》的城建）

| 建筑 | 作用 |
|---|---|
| 指挥部 | 营地等级，决定其他建筑的等级上限 |
| 围墙 / 路障 | 抵御尸潮，决定营地“安全值” |
| 瞭望塔 | 尸潮防御输出，提前预警 |
| 菜园 / 厨房 | 生产 **食物** |
| 废料场 | 生产 **木材 / 零件** |
| 医务室 | 生产 **药品**，治疗伤员、阻止感染 |
| 宿舍 | 决定幸存者人数上限 |
| 工坊 | 打造武器、装备和工具 |
| 无线电台 | 收到求救信号，触发招募和剧情事件 |
| 训练场 | 提升探索小队的战斗力 |

- **资源（4 种 + 1 种货币）**：食物、木材、零件、药品；另有“罐头”作为稀有货币（加速、招募、复活用，主要来自看广告和成就）
- **《无尽冬日》的“温度”机制替换为**：
  - **安全值**：围墙和瞭望塔的强度。太低时，尸潮会冲进营地
  - **士气**：受食物、住宿、事件选择影响。太低时，幸存者会怠工、吵架、甚至出走

### 4.2 幸存者系统（游戏灵魂）

- 每个幸存者都有：**头像、名字、性格标签、职业专长、健康、心情、人际关系**
- **性格标签示例**：乐观、自私、懒惰、勇敢、多疑、热心肠。性格会影响事件走向
- **职业专长**：厨师、医生、机械师、猎人、士兵、农夫。分配到对口的岗位效率更高
- **人际关系**：朋友、恋人、仇人。两个仇人一起干活会出事，恋人一起出队士气更高
- **死亡**：【已定，取代旧规则】任何人都可能死，包括核心角色。战斗中倒下有一定概率牺牲（医务室、卫生所营地能降低）；守夜失败会有人被咬死；长期挨饿挨冻会死人。前 6 个游戏日（第一个真实日）是新手保护期，不会死人。流浪者会不断投奔，补充人手
- **营地覆灭**：所有人都死了就是覆灭，显示存活天数和战绩，然后重新建立营地。**游戏比的就是存活天数**（跨局保留最长纪录、成就）
- **核心角色（英雄）**：少数有完整故事线的角色，拥有专属技能，担任探索小队队长。通过剧情解锁，不做抽卡

### 4.3 探索系统

- **大地图**：营地周围的城区，被迷雾覆盖。地点有超市、加油站、医院、警局、学校、商场、军事基地等
- **玩法**：选择地点 → 组建 2～4 人小队 → 出发（需要时间，离线时暂停）→ 途中随机触发事件卡 → 自动战斗 → 带回战利品
- **地点类型**：
  - 资源点：可以重复搜刮，产出固定类型的资源
  - 剧情点：推进主线
  - 危险区：丧尸多、奖励高，需要更强的小队
- 地图会随剧情季扩展，新的季节开放新的城区

### 4.4 战斗系统

- **【已定】自动战斗为主**：SD 小人和丧尸自动对打，玩家可以手动释放 1～2 个队长技能（如“燃烧瓶”“集火”），操作简单但有参与感
- **丧尸种类**：普通行尸、奔跑者、胖子（死后爆出毒气）、铁甲尸（前警察 / 士兵）、尸群首领
- **尸潮夜袭**：每隔一段时间，尸群会进攻营地，是塔防式的自动战斗。画面是一大群丧尸冲击围墙，**这也是做短视频宣传素材的最佳画面**
- 【待定】后期要不要加入敌对的人类势力（掠夺者、邪教营地）？《行尸走肉》的精髓就是“人比丧尸更可怕”，【建议】第二季再加入

### 4.5 事件与抉择系统（对应《行尸走肉》的剧情张力）

- 事件来源：探索途中、无线电台、营地内部、随机夜晚
- 每个事件给 2～3 个选项，后果可能是资源变化、士气变化、关系变化、有人加入或离开，或解锁后续事件
- **示例**：
  - 🚪 夜里一个受伤的陌生人敲门求救。【收留】可能获得新成员，也可能是被咬了；【拒绝】士气 -5，某位热心肠成员对你不满
  - 🍞 食物只够分给一半人。【平均分配】所有人心情下降；【优先战斗人员】探索效率提升，但老人和孩子不满
  - 🩸 队员阿杰在探索中被咬了。【立刻截肢】有概率救活但永久受伤；【让他自己决定】触发一段告别剧情；【隐瞒大家】……
- 所有事件都写在配置表里（不写死在代码中），**你以后不写代码也能加新事件**

### 4.6 剧情“季 / 集”结构

- 每一季大约 10 集，每集 = 一个主线目标 + 1～2 个关键抉择 + 结尾悬念

#### 主角：伊森·科尔（Ethan Cole）

**原型参考**《行尸走肉》的瑞克，保留的是人物类型，不照搬角色本身：

- **身份**：枫谷镇副警长，40 岁左右。镇上人人都认识他，是天生的领导者
- **性格**：正直、有责任感，重视每一条生命。但随着末日推进，他会被迫做出越来越冷酷的决定
- **核心矛盾**：“守住人性”还是“不择手段保护大家”？这正好对应玩家的抉择系统。玩家的选择会让伊森逐渐偏向“仁慈的领袖”或“铁腕的领袖”，不同倾向解锁不同的对话和剧情
- **个人动机**：尸潮爆发那天，他的女儿**莉莉**（12 岁）正在镇外参加学校夏令营，从此下落不明。找到她是伊森坚持下去的理由，也是贯穿第一季的主线悬念
- **形象**：深蓝警用夹克 + 小星形警徽 + 手枪，表情坚毅。【注意】不要使用瑞克标志性的牛仔警帽造型，避免撞形象
- **专属技能**：“掩护射击”（小队集火一个目标）；成长后解锁“领袖号令”（全队士气提升）

#### 初始幸存者（第一季开场）

| 角色 | 身份 | 性格 | 专长 | 故事钩子 |
|---|---|---|---|---|
| 伊森·科尔 | 副警长（主角） | 正直、坚毅 | 战斗 / 领导 | 寻找失踪的女儿 |
| 玛莎 | 超市老板娘，60 岁 | 热心肠、嘴硬 | 厨师 | 超市是她一辈子的心血，死也不肯离开 |
| 德里克 | 汽修工 | 暴躁、讲义气 | 机械师 | 他的弟弟在第一夜被咬，他一直没告诉大家…… |
| 苏菲 | 护理系大学生 | 胆小、善良 | 医生 | 成长型角色，从不敢看血到成为营地的医生 |
| 托比 | 加油站店员，20 岁出头 | 乐观、机灵 | 探索 / 搜刮 | 骑一辆破自行车，熟悉镇上每条小路 |

> 这些都是草案，名字、性格和故事都可以改，也欢迎你加新角色。

#### 第一季《第一夜》（草案）

- **开场（新手引导）**：夏夜，枫谷镇突发尸潮。伊森在执勤途中救下几名居民，一起逃进玛莎的超市。玩家第一次抉择：门外还有一个呼救的人，这时尸群已经逼近，开不开门？
- **第 1～3 集（MVP 范围）**：
  - 第 1 集“堵住大门”：搜集木材加固超市，打退第一次夜袭（教学：建造、战斗）
  - 第 2 集“空货架”：食物告急，派托比去加油站便利店搜刮（教学：探索、分配工作）
  - 第 3 集“无线电里的声音”：德里克修好了一台旧无线电，里面传出一个孩子的声音，报出的正是夏令营营地的呼号……（悬念结尾）
- **第 4～10 集方向**：扩建超市营地 → 伊森出发寻找夏令营 → 发现其他幸存者团体 → 季末：找到莉莉的线索，但营地遭遇前所未有的尸潮
- **后续几季方向**：【待定】比如迁往更安全的地方、与其他营地结盟或冲突、揭开病毒的来源……

#### 版权红线

- 玩法、题材和人物“类型”可以借鉴，但**不使用《行尸走肉》中的任何角色名、地名、标志性造型和原剧情**，比如瑞克、亚特兰大、农场、监狱、“醒来后发现世界末日”的医院开场
- 所有角色、地点和剧情都要原创

### 4.7 无尽生存（“比谁活得久”）

- **核心数据是“存活天数”**：**只按在线时间算**，在线约 10 分钟过一天；离线时营地暂停（不守夜、不死人），只发一点挂机收益（最多算 8 小时）。营地覆灭后显示战绩，跨局保留最长纪录，排行榜比的就是它
- **需要联网**：成绩实时上报排行榜，断网时营地暂停
- 尸潮从第 24 天起每 6 天强一级，没有上限；守夜失败有“喘息”（之后尸潮减弱），但会死人、丢物资
- 人会死，也会有流浪者投奔；营地人口在牺牲和补充之间起伏
- **换营地**：探索中会发现新的营地地点（加油站、河谷农场、镇卫生所、警长办公室、北岭水坝），每个地点有不同的优缺点。举营搬迁要付出代价：路上遭遇伏击、只能带走一半物资、路障要重建。北岭水坝是剧情的回报：伊森活着到达就能和莉莉重逢
- 每天在线 40 分钟的最低投入玩家，一周约 30 天、两个月约 240 天，第 80～100 天起开始有守夜败仗；看广告加速、做物品、选对营地的玩家能活得更久
- 新的剧情季以版本更新的方式推出，吸引老玩家回流
- **排行榜**：好友榜（微信开放数据域）+ 全服榜（微信云开发，服务器按真实时间校验天数，防止改存档刷榜）

## 5. 流量与传播设计（你说的“能不能火”）

微信小游戏的流量主要来自**买量（抖音、微信广告）、社交分享、平台推荐**三个方向：

1. **前 30 秒决定留存**：开场直接是“尸群冲进超市，你要选择救谁”的抉择，不要长篇背景介绍
2. **天生适合做短视频素材的画面**：
   - 尸潮冲击围墙的“爽”画面
   - “你会救他吗？”这类抉择画面，容易引发评论区讨论
   - 角色搞笑或感人的瞬间
3. **社交传播**：
   - 好友排行榜（存活天数）
   - 可分享的“营地海报 / 幸存者日记”卡片，比如“我的营地在末日中存活了 87 天，失去了 3 位同伴”
   - ⚠️ 微信禁止**诱导分享**（例如“分享才能获得奖励”），分享必须是玩家自愿
4. **回访钩子**：离线攒下一点挂机物资，上线就能看到排行榜名次变化，每集有悬念结尾

## 6. 变现方式

【建议】**先做纯广告变现（IAA），再考虑内购（IAP）**

- **原因**：在国内，带付费内购的游戏需要取得**版号**，个人开发者很难申请。纯广告变现的门槛低很多（但仍需要软件著作权、备案等资质，**上线前必须核实微信的最新政策和注册主体要求**）
- **激励视频广告（主要收入）**，玩家自愿观看：
  - 建造 / 探索立即完成
  - 探索收益翻倍
  - 救回重伤的幸存者
  - 离线挂机收益翻倍
  - 每日额外招募一次
- 插屏广告：少量使用，只在自然的停顿点（如一集结束时）出现，避免影响体验
- 以后如果取得版号：可以加入月卡、去广告、角色皮肤等

## 7. 美术与音效

- **美术场景**：美国乡村小镇，包括木屋、加油站、警长办公室、谷仓、小教堂、黄色校车、美式超市。角色使用英文名的中文译名
- **风格（已定）**：**现代日系动画赛璐璐**。事件头像、封面是正常比例的日漫立绘，战斗里是 2 头身的日系 SD 小人；低饱和的末日配色（灰绿、锈棕、水泥灰）加营地灯火的暖橙色，**不血腥、不猎奇**，更容易通过审核。详细规范和提示词见 [art-assets.md](art-assets.md)
- **视角**：【建议】斜 45° 的 2D 营地（类似《无尽冬日》的城镇视角），战斗采用横版侧视
- **素材来源**：AI 生成 + 免费素材
  - 先做一份“风格参考图”，固定提示词和配色，保证所有 AI 图风格统一
  - 免费素材：Kenney.nl、itch.io（注意查看每个素材的授权协议）
  - 背景音乐和音效：freesound.org 或 AI 生成，同样要注意授权
- ⚠️ 微信小游戏的**主包大小有限制（4MB）**，其余资源放在分包或 CDN 里，图片要压缩

## 8. 技术方案

- **引擎**：**Cocos Creator 3.8 + TypeScript**
  - 国内做微信小游戏最成熟的引擎，可以一键发布到微信和抖音
  - 免费，中文文档和教程多
- **数据驱动**：建筑、资源、幸存者、事件、剧情都写在配置表里（JSON，或由 Excel 导出），方便你自己调数值、写剧情
- **存档**：本地存储，【建议】以后再接入微信云存档，防止换手机后丢档
- **分工建议**：由我负责编写大部分代码和配置框架；你负责游戏设计、剧情事件文案、AI 美术生成、在 Cocos 编辑器里调整界面，以及试玩反馈

## 10. 风险与应对

| 风险 | 应对 |
|---|---|
| 同类游戏太多，没有特色 | 集中打磨“幸存者故事 + 抉择”这个差异点 |
| 版号 / 资质问题 | 先做纯广告变现，上线前核实最新政策 |
| AI 素材风格不统一 | 先定风格参考图和固定提示词，再批量生成 |
| 范围失控，做不完 | 严格按 MVP 清单来，新点子先记下来、以后再做 |
| 侵权 | 玩法可以借鉴，所有名字、剧情和美术都要原创 |
