### 像素字体

界面文字用 **Camp Pixel**：[缝合像素字体 Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font)（TakWolf）12px 比例宽度简体中文版的子集，SIL OFL-1.1 许可，可免费商用。按 OFL 要求，裁剪后的字体改了名字，许可证原文在 `assets/resources/fonts/LICENSE-fusion-pixel.txt`（需要随游戏一起发布）。

- 完整字体 1.4MB，`tools/subset_font.py` 只保留配置表和代码里出现过的字（约 1900 字、330KB）。
- **加了新文字以后要重新裁剪**：`pip install fonttools && python tools/subset_font.py`。`tests/font.test.ts` 会检查缺字。
- 字号会对齐到 6 的倍数（`widgets.ts` 的 `pixelSize`），像素才不会糊；emoji 和字体里没有的符号用系统字体显示。
- 所有文字都要经过 `widgets.ts` 的 `addLabel` / `styleLabel`，不要自己 `addComponent(Label)` 后直接设字号。

## 第一次打开项目

1. **安装引擎**：到 Cocos 官网下载 **Cocos Dashboard**，在 Dashboard 的“安装”页里安装 **Cocos Creator 3.8.x**。
2. **下载代码**：推荐用 [GitHub Desktop](https://desktop.github.com/) 克隆本仓库，并切换到 `claude/game-dev-initial-planning-ghtbzn` 分支。
3. **导入项目**：Dashboard →“项目”→“添加”（或“导入”），选择仓库文件夹。如果提示引擎版本不同，选择“升级”并继续。
4. **设置分辨率**：菜单“项目”→“项目设置”→“项目数据”，把设计分辨率设为 **720 × 1280**，勾选“适配宽度”。（v2.4.3 起 `ui/Bootstrap.ts` 会在运行时用代码设好竖屏 720×1280，这一步不做也可以；预览时在顶部机型下拉框选一款手机，比如 iPhone 12/13，看起来最接近真机。）
5. **创建主场景**（只需要做一次）：
   1. 在“资源管理器”的 `assets` 上右键 → 新建文件夹 `scenes`
   2. 在 `scenes` 上右键 → 新建 → Scene，命名为 `main`，双击打开
   3. 在“层级管理器”空白处右键 → 创建 → UI 组件 → **Canvas**
   4. 选中 Canvas，在“属性检查器”底部点“添加组件”，搜索 **GameRoot** 并添加
   5. `Ctrl + S` 保存场景
6. **预览**：点编辑器顶部的 ▶（选择“浏览器”预览）。能看到营地界面和开场事件“门外的呼救”就说明成功了。
7. 编辑器会生成很多 `.meta` 文件，**这些文件要一起提交到 Git**（它们记录了资源 ID，丢了场景就会坏）。

### 预览是一片灰屏 / 黑屏怎么办

灰屏说明 `GameRoot` 根本没有运行（游戏一启动就会先画一块深色背景）。

从 v2.4.2 起有 `ui/Bootstrap.ts` 兜底：运行时如果场景里没有 GameRoot（Canvas 丢了、场景是空的），会自动建一个 Canvas + 2D 相机把 GameRoot 挂上，所以**随便打开一个场景（哪怕是空场景）点预览都能进游戏**。如果还是灰屏，按顺序检查：

1. **编辑器底部“控制台”有没有红字**：有的话是脚本编译失败，截图发给开发者。
2. **场景里的 GameRoot 还在不在**：打开 `assets/scenes/main`，选中 Canvas，看属性检查器里有没有 GameRoot 组件；如果显示“Missing Script / 脚本丢失”或者没有，按上面第 5 步重新添加，`Ctrl + S` 保存。重新克隆仓库、`.meta` 没提交时最容易出现。
3. **预览的是不是 main 场景**：编辑器顶部预览按钮旁边的下拉框选 `main`（或者先双击打开 main 场景再预览）。
4. **浏览器按 F12 → Console**：看有没有红色报错。
5. 游戏运行中出错时，界面会显示“😵 游戏出错了”和错误信息（`GameRoot.showCrash`），截图发给开发者即可。

建议把 `assets/scenes/` 和所有 `.meta` 文件提交到 Git，换电脑或重新克隆时场景就不会丢。

### 联网与排行榜

游戏**需要联网**：启动时检查网络，没网显示“需要联网”和重试按钮；玩的过程中断网，营地暂停（这段算离线），连上后继续（`platform/Network.ts`）。

排行榜比的是**最长存活天数**（天数只按在线时间算），有两个榜：

| 榜 | 怎么实现 | 代码 |
|---|---|---|
| 好友榜 | `wx.setUserCloudStorage` 写入成绩，开放数据域读好友数据画在 sharedCanvas 上，主域用 `SubContextView` 显示 | `platform/Leaderboard.ts`、`build-templates/wechatgame/openDataContext/index.js` |
| 全服榜 | 微信云开发的云函数，服务器按真实时间校验天数，改存档刷不上去 | `build-templates/wechatgame/cloudfunctions/leaderboard/` |

每过一个游戏日、切到后台、营地覆灭时各上报一次。

**开通全服榜（只需要做一次）：**

1. 微信开发者工具打开 `build/wechatgame`，点工具栏的“**云开发**”，开通（有免费额度），记下**环境 ID**。
2. 把环境 ID 填到 `assets/scripts/platform/Leaderboard.ts` 的 `CLOUD_ENV_ID`，重新构建。
3. 在 `build/wechatgame/project.config.json` 里加一行 `"cloudfunctionRoot": "cloudfunctions/",`，开发者工具里就会出现云函数目录。
4. 右键 `cloudfunctions/leaderboard` →“**上传并部署：云端安装依赖**”。
5. 云开发控制台 → 数据库 → 新建集合 **`leaderboard`**，权限选“仅创建者可读写”（客户端不直接读写，全部经过云函数）。

没填 `CLOUD_ENV_ID` 或者在编辑器里预览时，排行榜用调试实现（只显示自己）。

**防刷校验**（`rules.js`，有单元测试）：服务器记下第一次看到这一局的时间，之后上报的天数不能超过“这段真实时间里全程在线最多能玩出来的天数 × 1.2 + 2”，多出来的直接截掉。云函数的 `config.json` 要和 `balance.json` 的时钟参数一致，`npm test` 会检查。

### 事件写法示例

```json
{
    "id": "my_event",
    "title": "事件标题",
    "text": "事件描述",
    "weight": 5,
    "once": true,
    "conditions": { "minDay": 2, "hasSurvivors": ["toby"] },
    "choices": [
        {
            "text": "选项文字",
            "cost": { "food": 10 },
            "outcomes": [
                { "weight": 3, "text": "好结果", "effects": [ { "type": "addSurvivor", "survivor": "hank" } ] },
                { "weight": 1, "text": "坏结果", "effects": [ { "type": "injure", "survivor": "random" } ] }
            ]
        }
    ]
}
```

- `weight`：随机抽取权重，`0` 表示只能由剧情触发；`outcomes` 里的 `weight` 决定各种结果的概率。
- `speaker`（可选）：事件卡上显示谁的头像（幸存者 id）。不写就自动用正文里第一个提到的人，都没提到就显示“营地”旁白。
- 可用的效果（`effects`）：
  - `resource`：增减资源
  - `mood`：改心情（`target` 可以是某个幸存者 id、`random` 或 `all`）
  - `addSurvivor` / `removeSurvivor`：有人加入 / 离开
  - `injure` / `heal`：受伤 / 治疗
  - `fall`：在危险里倒下，按死亡概率牺牲或重伤（新手保护期内只会受伤；`cause` 写死因）
  - `flag`：记下一个剧情标记
  - `triggerEvent`：接着触发另一个事件
  - `addWanderer`：随机生成一个流浪者加入（可以写 `specialty` 指定专长）
  - `discoverSite`：发现一个新的营地地点（`site` 写 sites.json 里的 id）
  - `stat`：累计一项统计数据（`amount` 默认 1），成就和悬赏都读统计。现有的：`diary_pages`（日记残页）、`quiet_moments`（宁静时刻）、`laughs`（欢笑）
  - `prop`：获得背包道具（`prop` 是 `props.json` 里的 id，`amount` 默认 1）
  - `livestock`：畜栏里加 / 减牲口（`animal` 是 `farming.json` 里的 id，`amount` 可以是负数；畜栏放不下的不算）
- 可用的条件（`conditions`）：`minDay`、`minSurvivors`、`flags`、`notFlags`、`hasSurvivors`、`minHq`（指挥部至少几级）、`minBuilding`（比如 `{"garden": 1}` 有了菜园才会发生）、`hasAnimals`（畜栏里有这些牲口，比如 `["chicken"]`）。
- **选项要有取舍**：随机事件（`weight > 0`，日记残页除外）至少 3 个选项，测试会检查。好的写法是“稳妥但收益小 / 冒险但可能大赚也可能有人受伤 / 花资源换确定的好处”。
- **选项提示**：界面在每个选项下面自动标出 `💰花费` / `🎲结果随机`（`outcomes` 不止一个）/ `⚠️有风险`（可能受伤、离开、扣资源或心情）/ `🎁可能有收获`，由 `choiceHints()` 从配置算出来，不用手写，也不会剧透具体结果。
- **结果卡片**：选完后弹出结果卡片，显示发生了什么和实际得失（`resolveChoice` 返回的 `effectsText`，对比选择前后的资源、道具、人员、心情），点“继续”再看下一个事件。

## 战斗系统

战斗是自动进行的横版对战，玩家可以手动释放每个角色的 1 个主动技能。代码在 `assets/scripts/core/battle/`，分成 5 个模块：

| 模块 | 文件 | 配置表 | 负责什么 |
|---|---|---|---|
| 1. 角色配置 | `units.ts` | `units.json` | 基础属性、外观、等级成长，生成战斗角色 |
| 2. 技能系统 | `skills.ts` | `skills.json` | 触发条件、目标选择、冷却、效果执行 |
| 3. 技能编排登记表 | `registry.ts` | — | 统一登记角色 / 技能 / 状态，检查配置错误，生成技能说明，调试时临时改数值 |
| 4. 伤害结算管线 | `damage.ts` | — | 增伤 → 暴击 → 防御减免 → 易伤 → 取整 → 护盾 → 扣血 |
| 5. 控制和状态 | `status.ts` + `Battle.ts` | `statuses.json` | 眩晕 / 定身 / 沉默、增减益、持续伤害、护盾；移动、索敌、普攻、刷怪、胜负判定 |

### 查看一场战斗的战报

```bash
npm run battle
```

会打印一场“五人小队 vs 尸群”的完整中文战报，改完数值后用它看效果。

### 数值平衡报告

```bash
npm run balance
```

每个探索地点、每种尸潮在不同的训练场 / 栅栏等级下各打 50 场，打印胜率和平均受伤人数。调整 `units.json`、`locations.json`、`raids.json` 之后跑一下，确认难度曲线是“越练越强、栅栏越高越稳”。

### 经济节奏报告

```bash
npm run economy
```

模拟一个“最低投入”的普通玩家玩 60 天真实时间：每天 8:00～22:00 每 2 小时上线一次，每次 5 分钟（游戏时间只在这 40 分钟里走），不看广告、不做物品、不接悬赏。报告按天打印游戏天数、指挥部等级、资源、士气、守夜战绩、尸潮加成（喘息值）、死亡人数和成就数，最后列出死因。调整任何经济数值后都应该跑一下，对照下面的目标曲线。

### 战斗在营地里怎么发生

- **探索**：在“探索”页派出小队（自动挑战斗力最高的 4 个人）。小队出发后离开工作岗位，到时间自动打一场战斗：
  - 打赢：带回战利品，并解锁下一个地点
  - 打输：什么都拿不到
  - 战斗中倒下的人会**受伤**（`injuryRecoveryMinutes` 游戏分钟，约 5 分钟在线），可以用药品在医务室立即治好
  - 打赢后这个地点要过 2 个游戏日（`locationRestockMinutes` = 160）物资才重新聚起来，才能再去；打下过的地方再去，战利品只有 `repeatLootFactor`（75%），好东西已经被搜走了
  - 看激励视频可以让小队立即返回
- **尸潮夜袭**：第 1 集结束后约 1 分钟来第一次（`firstRaidMinutes`），之后每个游戏日来一次，天数越往后尸潮越凶。
  - 所有能战斗的人和**栅栏**一起上阵，大家守在栅栏后面，栅栏生命 = 安全值 × 30
  - 撑到时间结束就算守住；**栅栏被拆就算失败**，会损失 10% 物资
  - 离线时营地暂停，不会有尸潮
- **训练场**：每升一级，所有幸存者的战斗等级 +1。
- 探索的战斗自动结算（手动技能自动释放）。每场战斗的参数和玩家的操作都存进了战报，“战报”页可以**回放**，结果完全一致。

### 亲手守夜（`core/liveRaid.ts` + `ui/BattleView.ts`）

界面开着时（`camp.liveRaids = true`），尸潮来了不会自动结算，而是放进 `state.pendingRaid`，界面切到战斗画面，实时演出：

- 每个有主动技能的角色一个按钮，冷却好了会亮起“点我！”。默认要玩家自己点，也可以打开“自动技能”。
- **修补栅栏**：花木材给栅栏回血，每次回 20% 生命，花费 = 回的生命 × 0.1（至少 10 木材），每场最多 3 次（`balance.raidRepair`）。
- 可以 2 倍速，也可以“跳过”（剩下的自动打完）。
- 战斗中关掉游戏：下次打开会从头再打这一场（同一个种子）。
- 测试和数值模拟里 `liveRaids = false`，照旧自动结算；没有界面在看时留着的尸潮也会自动打完。
- 所有操作记在 `BattleSetup.inputs` 里（放技能、切自动、修栅栏），战报回放时原样执行。

实测（`horde` / `great_horde`，5 人）：营地弱的时候，大尸潮完全不按技能必输、及时按技能必赢——按不按技能在关键时刻差别很大。

### 路边拾荒（`core/pickups.ts`）

营地附近平均每 10 游戏分钟（约 75 秒在线）出现一样东西——补给箱、废铁堆、急救箱、落单的行尸、罐头——显示成屏幕上方的金色按钮，点一下就捡走。最多同时 3 个，60 游戏分钟没人捡就消失。奖励随指挥部等级按探索战利品的倍率成长（罐头不成长）。配置在 `pickups.json`。

### 每日目标（`core/daily.ts`）

每个游戏日（在线约 10 分钟）从 `daily.json` 的任务池里抽 3 个小目标（同一种统计只抽一个），比如“消灭 15 只丧尸”“探索成功 1 次”“在营地附近捡 3 样东西”。完成后在“任务”页领奖励，3 个都领完再开一个宝箱。没领的第二天就没了。有东西可领时，“任务”页签会显示 ❗。

- 进度用统计数据判断（抽到时记下当前值），和悬赏一样。
- `conditions` 不满足、`requiresBuilding` 还没建的目标不会抽到（比如没开始守夜就不会抽到“守住 1 次尸潮”）。

实测：`npm run economy` 的模拟玩家顺手捡东西、领每日目标，经济曲线基本不变——它们是让等待时有事可做，不是主要收入。

### 流浪商人（`core/trader.ts`，资料库 R07）

第 2 天起，每隔 160 游戏分钟（约 20 分钟在线）有一辆破皮卡停在营地门口，待 60 游戏分钟。地图右下角出现 🚚，点开能看到 3 笔以物易物的交易（从 `trader.json` 的交易池随机抽），换到的数量在 ±25% 之间浮动；每笔只能换一次。看一次激励视频能让商人重新摆一批货。数量随指挥部等级成长（罐头不成长）。

### 侦察点（`core/scouting.ts`、`scouting.json`）

地图上已经亮起来的区域里，平均每 25 游戏分钟（约 3 分钟在线）冒出一个侦察点，最多 2 个，120 游戏分钟没人去就消失。点一下派一个人去（优先派闲着的人；在岗位上的人会离开岗位），`travelMinutes` 后回来：

| 侦察点 | 路程 | 带回 |
|---|---|---|
| 🚗 废弃的车 | 4 | 食物、药品（没有木材），可能有瓶装水、汽油、药箱、棒球棍、手枪、皮夹克 |
| 🪂 空投箱 | 8 | **第 10 天、指挥部 5 级以后才出现**。食物，可能有神秘补给箱、一箱口粮、防暴背心、猎枪 |
| 🆘 求救信号 | 6 | 触发营救过程（见下） |
| 🚪 地下储藏室 | 10 | 罐头、药品，可能有工具箱、咖啡 |
| 👣 尸群的足迹 | 5 | 零件，可能有巧克力 |

侦察的人回来时有 10% 概率受点伤（`injuryChance`）。侦察中的人算“在外面”，不能干活、不能出战。
侦察点可以写 `conditions`（和事件一样的条件，比如 `minDay`、`minHq`），不满足时不会刷出来。

**营救是一个过程**：求救信号先触发“镜子的反光”（硬冲进去 / 引开尸群 / 回去叫人 / 放弃），成功后接着“带他回家”（走大路 / 绕小路 / 先包扎）。路上用效果 `fall` 表示有人倒下：按死亡概率要么牺牲、要么重伤（新手保护期内只会受伤）。

### 营地变大会被发现

指挥部 6 级、第 8 天以后，会触发事件“被人盯上了”（条件 `minHq`），之后镇地图上多出两个营地：

- 🏴 **掠夺者营地**：敌人是活人（`raider` 掠夺者、`raider_gunner` 枪手，阵营 `raider`，击杀记在 `raiders_killed`）。训练场 2 级勉强能打，打下后触发“铁丝笼里的人”，能救出被关的人。
- ⛺ **陷落的河湾营地**：被尸群冲垮的大营地，救人概率高。
- 掠夺者营地没打下之前，随机事件“保护费”会来勒索。

### 背包道具（`core/props.ts`、`props.json`）

顶部状态栏右上角的“🎒背包”，得到新道具时亮红点。

| 类型 `type` | 道具 | 效果 |

| `resource` | 一袋 / 一箱口粮、一捆木板 / 一车木材、一盒 / 一箱零件、药箱、午餐肉罐头 | 打开得到 `reward`（按探索战利品倍率的**一半**指数随指挥部成长，罐头不成长） |

| `recall` | 对讲机 | 在外探索的小队立即回来 |
| `mood` | 咖啡、巧克力 | 所有人心情 +`amount` |
| `heal` | 野战医疗包 | 治好所有伤员 |

| `chest` | 神秘补给箱 | 按 `contents` 的权重随机开出一样（道具或资源） |

- 探索打赢：`locations.json` 每个地点的 `drops`（写进战报）
- 守夜守住：`raids.json` 的 `drops`
- 拾荒：`pickups.json` 每种东西的 `drops`
- 每日宝箱：`daily.json` 的 `chestProps`
- 流浪商人：`trader.json` 交易的 `getProps`（比如零件换工具箱）
- 事件：效果 `{ "type": "prop", "prop": "wrench", "amount": 2 }`
- 开局：`balance.startingProps`

### 轮流守夜与安静的夜晚（`core/watch.ts`）

- 每个人有**精力**（0～100）。每到晚上，按人数排出守夜的人（每 4 个人 1 个，至少 1 个）：守夜的人精力 -40，其他人睡一觉 +35。
- 精力低于 50 时，干活产量和战斗攻击打折扣，精力 0 时只剩 60%。
- 守夜安排在幸存者档案里改：**轮班**（默认，精力高的先上）/ **固定守夜** / **不守夜**。一直让同一个人守夜，他很快就会累垮。
- 守夜人手不够（有人受伤、外出，或者都设成了“不守夜”）时，如果尸潮来了，栅栏只有 70% 生命。
- **不是每晚都有尸潮**：第一次尸潮必来，之后每晚来的概率 = 55% + 每天 1%，最多 90%（`balance.raidChance`）。平静的夜晚记在 `quiet_nights`。
- 参数在 `balance.nightWatch`、`balance.raidChance`。幸存者页顶部显示今晚谁守夜和尸潮概率。

### 心情（`core/mood.ts`）

每个人的心情 0～100 分五档，每档有实际效果：

| 档 | 心情 | 效果 |
|---|---|---|
| 😄 开心 | 80+ | 打仗攻击 +5% |
| 🙂 平静 | 55+ | — |
| 😐 一般 | 30+ | — |
| 😟 低落 | 10+ | 干活产量 -15% |
| 😭 崩溃 | <10 | 不干活、不守夜，打仗攻击 -10% |

- 全营地的平均心情仍然是“士气”，影响所有人的产量。
- 改心情一律用 `changeMood(state, s, amount, 原因, now)`，原因会记在 `moodNotes`（最近 6 条，同一原因连着发生会合并），个人档案里显示心情条、正在影响心情的事（饿肚子、受伤、太累、吃饱了）和最近的原因。
- 会改心情的事：事件（记在事件名下）、守夜胜负、探索失败、道具、有人牺牲（所有人 -8）、守夜累垮（-4）、闲聊。

### 营地闲聊（`core/chatter.ts`、`chatter.json`）

- 平均每 6 游戏分钟，营地里两个人聊几句，显示成营地地图上的对话气泡，“📊 数值”面板里能看到最近的闲聊。
- `chatter.json` 里有 191 段手写对话：角色之间的日常、八卦别人（`about: "any"`，台词里写 `{x}`）、玩笑、暖心、担心、拌嘴。很多和剧情标记挂钩（莉莉回来了、有了狗、被掠夺者盯上……）。
- **不重复**：说过的记在 `state.chatterSeen`，能说的全部说完才重新开始一轮。
- 按 `moodByKind` 改说话人的心情（拌嘴 -2、玩笑 +2、暖心 +3……）。
- 写法：`{ "id": "...", "who": ["martha", "any"], "kind": "gossip", "about": "any", "conditions": {...}, "lines": [[0, "..."], [1, "..."]] }`，`lines` 的第一个数字是 `who` 里的序号。
- **日常寒暄**（`smalltalk.json`）：问好、晚安、四季天气、干活、吃饭、歇脚几个话题，每个话题的开场白 × 回答两两组合，自动生成约 300 段短对话（`{a}` 先说话的人、`{b}` 回答的人、`{town}` 小镇名；`season` 限定季节）。手写的对话被挑中的机会更大一些。

写法：`"stages": [{ "level": 1, "name": "篝火", "icon": "🔥", "description": "..." }, ...]`，第一个阶段从 1 级开始，等级从小到大。

### 探索背包（`core/packing.ts`、`packing.json`）

探索打赢以后，战利品摊在地上，要装进背包才能带回营地：

- 像三角洲那样，**每个人背自己的包**：不同的包有不同的格子区（没背包就只有两只手 2×2），开车再多一块后备箱。每件东西占 w×h 格，可以转 90 度，只能放在一块区里，不能重叠。
- 负重上限 = 每人 `carryPerPerson`（8）+ 包多背的 `carry` + 车的 `cargo`。

| 背包（装备位置“背包”） | 格子区 | 多背 | 来源 |
|---|---|---|---|
| 👝 腰包 | 2×1 + 2×1 | 2 | 加油站、废弃的车、工坊 1 级 |
| 🎒 书包 | 3×3 | 4 | 伊森开局背着；镇小学 |
| 📦 外卖箱 | 4×3 | 6 | 汽车旅馆、物流仓库 |
| 🏔️ 登山包 | 3×4 + 2×2 | 9 | 警长办公室、高速车祸、工坊 2 级 |
| 🪖 战术背包 | 4×4 + 2×3 + 2×2 | 14 | 军方检查站、掠夺者营地 |

- 资源打成一包一包（`packing.bundles`：食物 20 一包 1×1 重 2、木材 25 一包 2×1 重 4、零件 15 一包 1×1 重 3、药品 8 一包 1×1 重 1、罐头 4 一包 1×1 重 2），包的大小随指挥部等级和战利品一起成长。
- 道具在 `props.json` 写 `size`、`weight`（猎枪 1×3、防暴背心 2×2、一车木材 3×2……），不写默认 1×1 重 1。
- 界面：点地上的东西选中再点格子放，或者点“放进去”自动找位置；点背包里的东西拿出来；“自动整理”按价值重新装；“带回营地”确认，没装下的留在原地。
- 测试和模拟（`liveRaids = false`）自动装好带回来。

### 主角与普通幸存者

- **幸存者没有技能了**。除了主角伊森，所有人（包括玛莎、德里克这些有名有姓的角色）都是普通幸存者：同一种战斗单位 `militia`，靠天赋、装备、站位、搭配和羁绊区分。技能系统还留在战斗引擎里，给丧尸和工坊物品用。
- **伊森的天赋「浴火重生」**（`roster.ts` 的 `rebirth`）：本该牺牲时改为重伤（养伤时间加倍），之后 3 天冷却；每涅槃一次攻击永久 +5%；冷却中倒下，牺牲概率也只有别人的一半。尸群冲进营地咬人时也能涅槃。

### 站位与搭配（`core/formation.ts`）

- 每个人在档案里选站位：**自动**（拿枪的站后排，其他站前排）/ **前排** / **后排**。
- 前排先挨打，生命 +10%；后排站得靠后（x = -3 起），拿远程武器（手枪射程 4、猎枪 3、猎弓 5）的攻击 +10%。
- 搭配（同一支队伍里有就生效，出发前在地点卡片上列出来）：

| 搭配 | 效果 |
|---|---|
| ⭐ 有人领头（伊森） | 全队攻击 +5% |
| 💊 有医生跟着 | 全队生命 +5%，倒下的人牺牲概率减半 |
| 🛡️ 战士顶在前面 | 前排战士生命再 +10% |
| 🔦 有拾荒者 | 探索战利品 +15% |
| 🔧 有机械师 | 每个机械师让队伍多背 4 重 |
| 🤝 老搭档 | 和同队的人一起打过 3 场以上，每个这样的战友攻击 +3%（最多 +9%） |
| ❤️ 跟着伊森 | 和伊森同队时，按和伊森的羁绊攻击 +2%～+10% |
| ⚠️ 没人顶前排 | 提醒：后排会直接被扑到 |

- **自己挑队员**：探索地点卡片上点名字加入 / 移出小队（最多 4 人），也可以恢复自动编队。

### 羁绊与墓地（`core/bonds.ts`）

- 和伊森的羁绊 = 跟着他的天数 + 并肩作战次数 × 0.5，名字按档位上色：

| 羁绊 | 分数 | 颜色 | 和伊森同队攻击 | 牺牲时大家多掉的心情 |
|---|---|---|---|---|
| 陌生 | 0+ | 灰 | — | — |
| 熟识 | 3+ | 绿 | +2% | 2 |
| 信赖 | 10+ | 蓝 | +4% | 5 |
| 生死之交 | 25+ | 紫 | +7% | 8 |
| 老战友 | 50+ | 金 | +10% | 12 |

- **最初的伙伴**（⚜️）：开局就在、或者第一次探索遇到并留下的人。
- 两个人一起打过的仗记在 `state.bonds`（探索、守夜都算），用于“老搭档”搭配。
- **墓地**：有人死了，营地左下角出现墓地，记下名字、死因、第几天、跟着伊森多少天、并肩作战几次、羁绊颜色。每座墓每天可以祷告一次，所有人心情 +2～+8（感情越深、最初的伙伴越多）。

### 打猎和钓鱼（`core/hunting.ts`、`districts.json` 的 `hunting`）

- 在分区卡片上派 1～3 个人去打猎，6 游戏分钟后带回猎物（食物，随指挥部等级按一半指数成长）。
- 每个区适合打的东西不一样：

| 区 | 适不适合 | 猎物 |
|---|---|---|
| 超市街区 | 差 | 老鼠、鸽子 |
| 南部公路 | 一般 | 乌鸦、野兔、鹿 |
| 南郊教堂区 | 一般 | 野兔、走失的鸡、鸽子 |
| 西区工坊街 | 差 | 老鼠、野狗⚠️ |
| 东区公园 | 好 | 野兔、松鼠、野鸭、湖里的鱼、野狗⚠️ |
| 河畔老城 | 好（钓鱼） | 河鱼、大鲶鱼、野鸭 |
| 东北医院区 | 一般 | 浣熊、鹿 |

- 野猪、野狗会伤人。远的区一样要交通工具。新武器 🏹 猎弓（工坊 1 级能做，射程 5）。
- 畜栏有空位时，有的猎物能**活捉**回去养（`capture`）：走失的鸡 60%、走失的山羊 50%、野兔 25%、野鸭 20%、野猪（猪崽）12%。

### 种菜和养殖（`core/farming.ts`、`farming.json`）

两个新建筑，都在营地地图最上面一排；有事可做时建筑左上角会冒出小气泡（🧺 收菜、🌱 能种、🥚 收蛋、🤗 照看、⚠️ 挨饿，见 `badges.ts` 的 `farmTodos`）。

**菜园**（指挥部 2 级开放）：🪴花盆 → 🌱菜畦（3 级）→ 🥬菜园（6 级）→ 🏡温室大棚（10 级）。

- 每级有几块菜地（`plots`，1 级 2 块，之后每 2 级 +1）。菜园第一次建好会送几包开局种子。
- 用种子种下（菜园面板里点，或者在背包里“种下”），熟了点“收获”：得到食物（草药得到药品）和 1～3 颗种子，所以能一直种下去。**熟了 1 天不收就烂在地里。**
- 生长速度 = 季节（夏 1、秋 1.15、春 1.1；**冬天露天种不了**，温室大棚里 0.6）×（1 + 0.25 × 在营地的农夫，最多算 2 个）。番茄怕冷，玉米、南瓜只能夏秋露天种。
- 收成和打猎一样随指挥部等级成长。

| 作物 | 成熟（游戏分钟） | 收成 | 季节 |
|---|---|---|---|
| 🥬生菜 | 30 | 🍞10 | 全年 |
| 🥕胡萝卜 | 45 | 🍞16 | 全年 |
| 🍅番茄 | 50 | 🍞20 | 夏秋春 |
| 🥔土豆 | 70 | 🍞30 | 全年 |
| 🌿草药 | 80 | 💊5 | 全年 |
| 🌽玉米 | 120 | 🍞60 | 夏秋 |
| 🎃南瓜 | 160 | 🍞90 | 夏秋 |

**畜栏**（指挥部 3 级开放）：🐔鸡笼 → 🐐畜栏（3 级）→ 🐖小农场（6 级）→ 🐄牧场（9 级）。每级能养几只（`pens`，1 级 4 只，之后每级 +2）。
**先养小动物，升级后才能养大的**（`minLevel`）：鸡、兔子 1 级，鸭 2 级，山羊 3 级，猪 6 级。等级不够时活捉不了、道具用不了。

**鱼塘**（指挥部 3 级开放）：🪣水缸 → 🐟鱼池（3 级）→ 🎣鱼塘（6 级），1 级养 4 条，之后每级 +3（和畜栏分开算，`space: "pond"`）。鲫鱼 1 级、草鱼 3 级、鲶鱼 5 级。钓鱼时有机会带活鱼回来，商人卖鱼苗，河边码头会捡到鱼苗。鱼和牲口一起每天喂食，两条以上会繁殖，可以捞上来吃。

- 牲口来源：打猎活捉、商人（小鸡、兔子、小山羊、猪崽、各种种子）、探索掉落、事件。
- **每天换日时喂一次**，从仓库扣食物。吃饱了才会下蛋 / 产奶（攒在畜栏里，最多攒 3 天，点“收”）、两只以上才会生崽；**没吃的会挨饿，连续饿 2 天饿死一只**（吃得最多的先死）。
- 可以宰了吃肉；每天可以“照看牲口”一次，全员心情 +3。

| 牲口 | 每只每天吃 | 产出 | 宰了 | 生崽 |
|---|---|---|---|---|
| 🐔鸡 | 🍞3 | 🥚鸡蛋 🍞9 | 🍞15 | 15% |
| 🦆鸭 | 🍞3 | 🥚鸭蛋 🍞8 | 🍞16 | 10% |
| 🐇兔子 | 🍞2 | — | 🍞14 | 35%（一窝 1～3 只） |
| 🐐山羊 | 🍞6 | 🥛羊奶 🍞18 | 🍞45 | 6% |
| 🐖猪 | 🍞8 | — | 🍞120 | 10%（一窝 1～3 只） |

- 相关事件：菜园闹虫、鸡笼边的脚印（狐狸）、牵着羊的老太太、丰收、兔子打洞跑了。招募特质新增“带着种子”。
- 界面模式由玩家亲手种、收；测试和模拟（`liveRaids = false`）由 `autoFarm` 自动收菜、收蛋、种满空地。

### 时间：时钟、跳到晚上、倍速（`core/clock.ts`）

- 状态栏显示现在几点和“🌙 X 后入夜”（`timeOfDay`）：尸潮在 22:00 来，按离下一次尸潮的时间倒推时钟；快入夜时变红。
- “⏩ 跳到晚上”（状态栏和设置里都有，`CampGame.skipToNight`）：游戏时间直接快进到下一次尸潮；尸潮还没开始时跳到第二天。中间的产出、探索照常结算。统计 `time_skips`。
- 设置里的倍速 ×1 / ×2 / ×4（`clock.speed`）。注意：排行榜按真实在线时长限制天数，长时间加速玩出来的天数可能会被截断。

### 上门的人（`core/visitors.ts`）

- “栅栏外的流浪者”“逃难的车队”这类会有人加入的事件（`addWanderer` 效果），事件一出现就把人生成好，事件卡上先显示表面信息：名字、来历、专长、性格、印象（隐藏的坏毛病只显示一个印象）。
- 选了收留，进营地的就是卡上那几个人。没有招募配置时（老配置）按老办法当场生成。

### 熟悉的丧尸（`core/familiar.ts`，资料库 R58）

- 死在外面的人（探索中牺牲）遗体留在原地，墓地里显示“🕳️ 尸骨未归”。
- 过 `balance.familiarZombie.delayDays` 天后，每次尸潮有 `chance` 的概率，他会变成行尸混在尸群里（头顶紫色名字，出场时飘字“那是……XX？”）。生命 / 攻击按 `hpMult` / `atkMult` 加强。
- 打倒他：把遗体带回营地安葬（墓地改成“🪦 带回营地安葬了”），大家先难过、再释然（心情 -4 +6）。没打倒：他会再回来。
- 战斗单位的 tag 是 `grave:墓地id:名字`，回放也能显示名字。

### 信号弹（`core/familiar.ts` 的 `fireFlare`，资料库 R57）

- 背包道具 🎆信号弹（商人卖、军方检查站 / 车祸现场 / 掠夺者营地等地方掉落）。
- 发射后 `balance.flare.candidates` 个幸存者循着信号来投奔（进候选人名单，和探索遇到的人一样决定留不留）。
- 代价：**当晚一定有尸潮**（不掷“安静的夜晚”），尸潮等级 +`raidBonus`，标题带“信号弹·”。今晚过去之前不能再放。

### 出大红（稀有品，资料库 R62）

- 道具写 `rare: true` 就是稀有品：在背包或战利品里一出现，界面全屏提示“🟥 出大红了！”。
- 现在有 5 件（`type: "treasure"`）：金表、金条、军用电台、发电机组件、一箱抗生素。掉率 1%～4%，只在难的地点和远的分区。
- 卖掉得到一大笔物资（随指挥部成长）；流浪商人在营地时卖，多给 `trader.treasureBonus` 倍。

### 今日情报（`core/intel.ts`、`intel.json`，资料库 R79）

- 每天给 `perDay` 个现在能去的分区各一条情报，显示在探索页地图下面和分区卡片里（探索页红点每天一次）。
- 情报改当天出发的打猎（`hunt`）、钓鱼（`fish`）成功率，勘察带回的资源（`loot`），受伤概率（`danger`）。比如“鹿群出来了”打猎 ×1.6，“聚了一大群行尸”危险 ×2.5 但收获 ×1.8。
- 选哪几个分区用天数做哈希，同一天结果固定，也不影响其他系统的随机数。

### 伊森的日记（`core/diary.ts`、`diary.json`，资料库 R55）

- 每过一天，伊森把这一天写成一篇日记：开头看大家的心情，偶尔一句季节，然后是谁加入、谁走了、谁死了，再挑最多 4 件当天的事（守夜、探索、收菜、打猎……按 `diary.json` 的 `stats` 顺序），最后一句收尾。
- 设置里的“📖 伊森的日记”和营地右下角的日记本都能打开，有新的一篇时带红点。最多保留 `keep` 篇。
- 伊森不在了，由营地里的其他人接着写。句子用天数哈希挑，不影响随机数。

### 单人开局与招募（`core/recruits.ts`、`recruits.json`）

- 新的一局**只有伊森一个人**（`balance.startingSurvivors`），开场剧情也是他一个人守着超市。
- **第一次探索回来**（不管输赢）一定会在路上遇到 1～3 个人（`firstCount`）：有名有姓的角色（玛莎、德里克、苏菲、托比、里奥、汉克、罗莎、诺拉、老乔，各有见面介绍）或者随机流浪者。之后打赢探索时按地点的 `recruitChance` 偶尔再遇到一个。
- 界面上逐个显示介绍、专长、天赋、性格和“印象”，由玩家决定**留下**还是**让他走**（有名有姓的人被拒绝后不会再出现）。测试和模拟自动决定。
- **特质**（`quirks`）有好有坏，决定留下谁的后果：

| 特质 | 好坏 | 效果 |
|---|---|---|
| 🎒 带着物资 / 🏏 带着家伙 | 好 | 加入时带来食物木材 / 一件武器 |
| 🍄 会找吃的 / 🌟 开心果 | 好 | 每晚多一点食物 / 大家心情 +1 |
| 💪 皮糙肉厚 / 🔨 闲不住 | 好 | 打仗生命 +15% / 干活 +10% |
| 🤒 生着病 | 坏 | 加入时就是伤员 |
| 🍖 大胃王 / 🥱 懒散 / 😰 胆小鬼 | 坏 | 每晚多吃 12 食物 / 干活 -25% / 攻击 -15% |
| 🦝 手脚不干净 / 🍺 酒鬼 / 💢 爱挑事 | 坏（藏着） | 时不时偷粮食 / 偷喝酒精 / 跟人吵架，第一次发作才暴露 |
| 📢 嘴不严 | 坏（藏着） | 每晚尸潮概率 +10%，4 天后才发现 |

- 藏着的坏毛病见面时只显示一句看不出好坏的“印象”（比如“看起来老实巴交”）。
- 测试默认用 5 人开局（`tests/helpers.ts` 的 `CLASSIC_START`），测单人开局用 `loadConfig({ soloStart: true })`；`npm run economy` 用真实的单人开局。

### 其他

- **每局随机地名**（`core/names.ts`、`names.json`）：开局给小镇、9 个分区、每个探索地点各抽一个名字（名字保留地点类型，比如“麦克斯加油站”“白十字诊所”），这一局一直不变。显示地名一律用 `locationName()` / `districtName()` / `townName()`。
- **黄金**（`core/gold.ts`、`balance.gold`）：开局 60 两，在背包页每次花 10 两换资源；前 6 天全价，之后越来越不值钱，第 24 天后没人要。
- **人死在哪，装备就在哪**：探索时牺牲的人身上的装备留在那个地点（地图上显示 💀），下次打下那里才能捡回来；死在营地附近的装备留在营地。
- **建筑按顺序开放**（`buildings.json` 的 `unlock`）：开局有指挥部、栅栏、厨房、废料场、宿舍；医务室要 3 个人，工坊要指挥部 2 级和 3 个人，训练场要指挥部 3 级，地窖要指挥部 4 级。
- **高难度地点后移**：地点条件里加了 `minHq`，比如警长办公室要指挥部 5 级、第 6 天，信号塔 7 级，掠夺者营地 11 级、第 30 天，军方检查站 12 级。
- **设置菜单**（状态栏右上角 ⚙️）：暂停 / 继续（暂停时游戏时间不走，也不算离线收益）、重新开始（按两次确认）、玩法说明。

### 营地数值（`core/campStats.ts`）

状态栏右下角“📊 数值”打开营地数值总览：日子、人口 / 床位、干活 / 空闲 / 外出 / 养伤人数，每种物资的库存 / 上限和每天净变化，平均心情、平均精力、太累的人，安全值、栅栏生命、战斗等级、今晚守夜、尸潮概率、下一次尸潮，探索进度，以及生存记录。需要警惕的数值标红。

### 红点（`core/badges.ts`）

底部页签、地图上的“营地地点”和商人都会显示红点：

| 地方 | “新内容”（打开后消失） | “可以做”（做完消失） |
|---|---|---|
| 幸存者 | 新加入的人 | 有人闲着、岗位有空 |
| 探索 | 新解锁的地点 | 小队可以出发 |
| 任务 | 新出现的悬赏 | 每日目标 / 悬赏有奖励可领 |
| 工坊 | 新能做的物品 | — |

### 幸存者档案与天赋（`core/talents.ts`、`talents.json`）

- 点“幸存者”页的人物卡片打开个人档案：头像、称号、专长、状态、心情、战斗等级 / 生命 / 攻击、性格、天赋、背景故事。
- 档案里可以**自由选择去哪里工作**：每个建筑一个按钮，显示空位和这个人在那里的产量倍率（专长对口、天赋加成），也可以让他休息、给伤员用药。
- 每个人有 1～2 个天赋（`survivors.json` 的 `talents`），流浪者随机得到 1 个（`wanderer: false` 的天赋只属于主要角色）。天赋效果：

| 效果 | 写法 | 例子 |
|---|---|---|
| 干活产量 | `work: { building?, mult }` | 巧手大厨：厨房 ×1.3；勤快：所有岗位 ×1.15 |
| 战斗 | `combat: { atk?, hp? }` | 老兵：攻击 ×1.25；铁打的身子：生命 ×1.25 |
| 伤愈时间 | `recovery` | 恢复力强：×0.5 |
| 侦察来回时间 | `scout` | 飞毛腿：×0.6 |
| 心情恢复 | `moodRecovery` | 乐天派：×2 |

新增天赋效果时同步 `TalentDef`、`talents.ts` 和 `validate.ts`。

### 安排工作（`core/workers.ts`）

- 建筑详情里可以“＋ 派一个人来”（优先专长对口的）/“－ 撤下一人”（优先不对口的）。
- “幸存者”页的“一键安排工作”：食物在减少就先派去厨房，否则先去废料场，再是医务室；专长对口的人优先去自己的建筑。

### 新手引导（`core/guide.ts`）

不用单独写引导脚本：根据当前剧情集的第一个未完成目标，算出“下一步”，界面顶部显示提示条，并把要点的页签、建筑、按钮高亮成金色（带 👉）。

- 开局没人干活 → 高亮“幸存者”页的“一键安排工作”
- 升级建筑 → 高亮对应建筑；需要先升指挥部就指向指挥部；正在升级就指向“看广告加速”
- 搜刮地点 → 高亮“探索”页对应地点的“派出小队”
- 第 1 集结束后提示“尸潮就要来了”

### 技能写法

```json
{
    "id": "molotov",
    "name": "燃烧瓶",
    "description": "德里克扔出燃烧瓶，点燃一片敌人。",
    "trigger": { "type": "active" },
    "cooldown": 15,
    "targeting": { "rule": "nearestEnemy", "radius": 2 },
    "effects": [
        { "type": "damage", "ratio": 1.2, "damageType": "fire" },
        { "type": "status", "status": "burn", "duration": 4, "power": 0.3 }
    ]
}
```

- **触发方式 `trigger.type`**：`active` 手动释放、`auto` 冷却好了自动释放、`onAttack` 普攻时按 `chance` 概率触发、`battleStart` 开战时触发、`hpBelow` 生命低于 `ratio` 时触发一次、`onDeath` 死亡时触发。每个角色最多 1 个 `active` 技能。
- **目标 `targeting.rule`**：`self`、`currentTarget`、`nearestEnemy`、`randomEnemy`、`lowestHpAlly`、`allAllies`、`allEnemies`；加上 `radius` 就变成范围技能（主目标周围 N 格内的同阵营单位都会被命中）。
- **效果 `effects`**：
  - `damage`：伤害 = `ratio` × 攻击力，`damageType` 可选 `physical` / `fire` / `poison` / `true`
  - `heal`：治疗 = `ratio` × 攻击力
  - `status`：施加状态，持续 `duration` 秒；持续伤害和护盾的强度 = `power` × 攻击力
- **伤害类型**：物理受全额防御减免，火焰受一半，毒素和真实伤害无视防御。防御公式：减伤 = 防御 / (防御 + 100)。

## 营地生活系统

### 季节与过冬

季节按“存活天数”循环：夏 3 天 → 秋 3 天 → 冬 3 天 → 春 3 天。
- **夏**：食物坏得快（腐烂 ×1.5）。
- **秋**：厨房产量 ×1.2，适合囤粮囤柴。
- **冬**：厨房产量减半、腐烂变慢；每人每分钟烧 0.08 木材取暖，没柴会挨冻（心情下降）。第一次入冬触发事件“第一场雪”。
- **春**：一切恢复正常，熬过冬天会记入成就。

### 食物腐烂

新鲜食物每分钟坏掉 0.1%（乘以季节倍率），囤得越多坏得越多。**罐头永不过期**。建造**地窖**可以让食物坏得慢 30% / 50% / 70%。

### 工坊

建造工坊后可以制作燃烧瓶、急救包，2 级工坊可以制作钉子炸弹。物品在探索和守夜时自动分给上阵的人，**在战斗中真的用掉了才扣库存**。燃烧瓶和急救包都要用药品（酒精），需要取舍。

### 尸潮：血月夜和营地的狗

- **血月夜**：每第 4 次尸潮是血月夜，尸群多一半，守住后奖励翻倍。顶部会提前预警。
- **营地的狗**：通过事件“跟回来的狗”收养后，守夜时会一起上阵，还会咬住行尸拖慢它们。
- **钢板栅栏**：栅栏新增第 4 级，是应对血月大尸潮的后期目标。

### 悬赏板

在“悬赏”页接取，最多同时 3 个。完成后领取奖励和猎人经验，猎人等级分为见习猎人、猎人、老练猎人、传奇猎人，等级越高能接的悬赏越难。悬赏目标用统计数据表示，比如 `kill_walker`（击杀行尸数）、`clear_clinic`（清理卫生所次数）、`raids_won`（守夜胜利次数），接取之后再增加指定数量就算完成。

### 成就

24 个成就，奖励罐头。条件和剧情目标用同一套写法（`buildingLevel` / `resource` / `flag` / `survivors` / `stat` / `day`），解锁时会弹出提示。`hidden: true` 的成就解锁前显示为“？？？”。

## 无限流经济

目标是长期游玩：没有“升满”的一天，尸潮压力持续上涨，但不会让玩家陷入必输的死循环。

### 时间：只算在线时间

- **游戏时间只在在线时走**（`core/clock.ts`）：1 秒在线 = 8 秒游戏时间（`balance.clock.onlineTimeScale`）。游戏里的一天是 80 游戏分钟（`dayLengthMinutes`），也就是**在线约 10 分钟过一天**。
- 界面每秒调用一次 `camp.online(Date.now())`。两次调用间隔超过 15 秒（`clock.onlineGapSeconds`）就算离线：切后台、关游戏、断网都算。
- **离线时营地暂停**：不吃饭、不守夜、不死人，建造 / 探索 / 养伤的计时也停住。
- **离线挂机收益**（`core/offline.ts`）：回来时按当前工人的产量发一小笔食物、木材、零件——离线 1 分钟 = 0.25 游戏分钟的产量，最多算 8 小时，不足 5 分钟不发（`balance.offline`）。8 小时离线大约相当于半天的产量。
- 改手机时间没用：往前拨只会被当成离线；往回拨再拨回来，拿不到重复的离线收益（`clock.maxRealAt`）。
- 所以**存活天数 = 在线时长**，排行榜比的就是谁在线撑得久。界面上的倒计时都换算成在线的真实秒数（`realSeconds()`）。
- core 里所有的 `now` 都是游戏时间，界面上的操作用 `camp.now`，不要传 `Date.now()`。
- 尸潮每个游戏日一次；季节、新手保护期、剧情里的“第 N 天”都按游戏日算。

### 建筑无限成长

`buildings.json` 里前几级手写（新手期可以精调），之后用 `scaling` 公式自动生成到 `maxLevel`：

```json
"scaling": { "maxLevel": 25, "costGrowth": 1.5, "timeGrowth": 1.32, "productionGrowth": 1.1, "slotsEvery": 3 }
```

- 每一级的花费 ×1.5、时间 ×1.32、产量 ×1.1，越往后升级越难，但永远有下一级。
- 生成的等级要求指挥部达到同样的等级（建筑不能超过指挥部）。
- 指挥部的仓库容量每级 ×1.6，比花费增长得快。**配置检查会自动发现“仓库存满也不够升级”的死局**，`npm test` 会报错。
- 游戏启动和测试都会先调用 `expandConfig()` 展开公式，其他代码只看展开后的 `levels`。

### 无尽尸潮与喘息

- 从第 22 天开始，每过 5 天所有尸潮丧尸 +1 级，奖励 ×1.15（指数增长），尸潮名称后面会显示“+N”（`balance.raidScaling`）。
- **喘息机制**：守夜失败一次，之后尸潮加成 -2；每守住一次恢复 1。打得过的玩家面对的威胁会一直上涨，被打趴的玩家有机会缓过来。
- 统计 `best_raid_level` 记录守住过的最高加成，可以作为排行榜指标（成就：尸潮渐涨 / 屹立不倒 / 末日灯塔）。
- 守夜失败损失 10% 物资（不含罐头）。

### 探索随营地成长

指挥部每高一级，探索的敌人 +0.5 级（向下取整），战利品 ×1.25。

### 看广告加速

每看一次，剩余建造时间减少 25%（至少 30 游戏分钟，约 4 分钟在线），短的升级直接完成。后期升级要很多个游戏日，一次广告不会直接完成。

### 目标曲线（`npm run economy` 的最低投入玩家）

模拟玩家每天上线 8 次、每次 5 分钟（一天在线 40 分钟 ≈ 4 个游戏日），顺手捡东西、领每日目标、打开背包里的资源箱和加速道具。

| 真实天数 | 1 | 2 | 7 | 14 | 21 | 30 | 45 | 60 |
|---|---|---|---|---|---|---|---|---|
| 游戏天数 | 5 | 9 | 29 | 57 | 85 | 121 | 181 | 241 |
| 指挥部等级 | 3 | 5 | 10 | 14 | 15 | 17 | 19 | 20 |

- 从不断粮。
- 模拟玩家每分钟都会派小队（至少 3 人）去当前能去的地点，打输的地点等训练场升级后才再去；会派人勘察分区、能修车就修车、把背包里的装备穿上。探索战利品按背包格子和负重自动装。
- 从单人开局起步：第一次探索回来招到人，第 2 个真实日（第 9 个游戏日）营地约 7 人，一周后 17 人。
- 模拟玩家比较莽：高难度地点一开放就去打，但高难度地点按指挥部等级开放，前 120 个游戏日只牺牲 4 人左右。
- 尸潮从第 18 天开始每 4 天强一级；第 180～240 个游戏日开始频繁守夜失败（60 个真实日约守夜 211 次、失败 18 次），喘息机制把尸潮稳定在玩家能勉强应付的水平。
- 背包道具让前期明显宽裕，但资源箱只按一半的指数随指挥部成长，后期只是锦上添花，不会冲淡无尽尸潮的压力。
- 营地等级大约能扛住 2 倍于自身等级的尸潮加成（见 `npm run balance` 的“无尽尸潮”表）。

## 生存竞赛：死亡、覆灭与换营地

**游戏比的是存活天数。** 人会死，营地会覆灭，也可以举营搬迁。

### 死亡

| 怎么死 | 说明 | 配置 |
|---|---|---|
| 战斗中倒下 | 30% 概率牺牲，否则重伤。医务室每级降低 3%（最多 70%），卫生所营地再减半。**探索打赢时倒下的人只会受伤**（队友会背回来） | `deathChanceOnFall`、`deathReductionPerInfirmaryLevel` |
| 守夜失败 | 尸群冲进营地，1 人被咬死（优先不是核心角色的人） | `raidBreachDeaths` |
| 饥寒 | 连续挨饿或挨冻累计 2 个游戏日（约 20 分钟在线）死 1 人，吃饱穿暖后重新计时 | `hardshipDeathMinutes` |
| 事件 | `removeSurvivor` 让人离开营地 | — |

- 前 6 个游戏日（约 1 小时在线）是**新手保护期**，不会死人（`deathGraceDays`）。
- 核心角色也会死。死者会记下剧情标记 `dead_<id>`，事件可以用 `notFlags` 避开已经死去的人。
- **流浪者**会通过事件投奔，探索打赢时也有概率救回一个（地点的 `recruitChance`）。他们的名字、职业、性格随机生成（`wanderers.json`），用“幸存者”角色战斗，专长对口同样有加成。
- 代码里查幸存者资料一律用 `survivorInfo()`（流浪者不在 `survivors.json` 里）。

### 营地覆灭

所有人都死了就是覆灭，时间停止，界面显示本局战绩和历史纪录，然后可以建立新的营地。**跨局保留**（单独存档 `doomsday-camp-records`）：最长存活天数、局数、累计天数、最近 10 局的战绩、已解锁的成就（新的一局不会重复发成就奖励）。

### 换营地

| 营地 | 怎么发现 | 优点 | 缺点 |
|---|---|---|---|
| 🏪 枫谷超市 | 开局 | 什么都有一点 | 没什么特别 |
| ⛽ 镇口加油站 | 打下加油站便利店 | 零件 +40%，每分钟自产零件 | 安全值 -40% |
| 🌾 河谷农场 | 打下五金店 | 食物 +60%，每分钟自产食物 | 安全值 -25%，食物坏得快 |
| 🏥 镇卫生所 | 打下镇卫生所 | 药品翻倍，伤好得快一倍，战死概率减半 | 尸潮 +2 级 |
| 🚓 警长办公室 | 打下警长办公室 | 安全值 +40%，战斗等级 +2 | 食物 -20% |
| 🏞️ 北岭水坝 | 日记第 4 页 | 安全值翻倍，尸潮 -3 级，床位 +6，每分钟自产食物 | 木材 -30%，路上最危险 |

搬迁的代价：
- 每人路上吃 20 食物。
- 所有能战斗的人都要打一场伏击战，倒下的人可能牺牲。
- 只能带走一半物资（罐头、工坊物品全部带走）。
- 栅栏等级按新地点的 `wallRetention` 保留，但不低于新地点自带的 `minWallLevel`。其他建筑保留。
- 搬完 3 天内不能再搬。
- 到达北岭水坝时，如果伊森还活着，会触发和莉莉的重逢。

### 普通玩家能活多久（`npm run economy`）

最低投入的模拟玩家（每天在线 40 分钟）：前 30 个游戏日几乎没有人死亡；第 80～100 个游戏日起守夜开始出现败仗，陆续有人牺牲，靠流浪者补充人手；60 个真实日（约 240 个游戏日）后仍然存活，但尸潮加成一直在涨。看广告加速、做物品、选对营地的玩家能活得更久。
